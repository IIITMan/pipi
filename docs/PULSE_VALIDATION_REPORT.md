## 1. 验证什么

PULSE 不验证"台词好不好听"，只验证一件事：**注入真实作息与事件后，生命模块的内部动力学是否呈现类似生命的形态**——
有潮汐、有突发、有平复、有昼夜节律、会因经历而改变，而不是随机噪声、死数值或 LLM 台词。

| 设计支柱（DESIGN §1） | 对应机制 | 验证阶段 |
|---|---|---|
| 自稳态张力（困/孤独/好奇） | Tension · 派生呼吸 | P0 / P1 |
| 对下一刻的预期（意外→惊讶） | 习惯化门控（loop） | P0 / P2 |
| 不可逆的具身时间线（我因经历变厚） | Bond · River · 气质字段 | P3 / P4 |

## 8. 验证中发现并修复的问题（验证驱动开发）

验证不是走过场——每个阶段首跑都暴露了真实问题，修复后才进入下一阶段。

| 阶段 | 首跑暴露的问题 | 根因 | 修复 |
|---|---|---|---|
| P1 | 呼吸 rate 指数爆炸到 1e15+ | 显式欧拉一阶滞后在 dt=60s ≫ τ=4s 时振荡 | Rhythm 改**解析解** `goal+(cur-goal)e^(−t/τ)`，任意 dt 稳定 |
| P1 | 惊吓当帧看不到、睡眠呼吸无差异、睡中仍挣扎、昼夜阶跃、Will 漏判 | 5 处数值/语义缺陷 | 独立惊吓脉冲 `_burst`；睡眠加深+降噪；睡中挣扎抑制；昼夜连续曲线+滞回；Will 改累加器 |
| P2 | 准时回家被误判"又惊又喜" | 事件注入用行驱动时钟（只累加打印行，严重滞后仿真时钟） | 改**分钟驱动** + 显式 `minute`；惊喜学习/判定限定傍晚 16–23 点 |
| P2 | 惊吓后意图无反应 | 分支未打断 Will | 惊吓分支补 `will.interrupt()`（挂起重试，超 3 次放弃） |
| P3 | 白天到达污染傍晚预期 | 惊喜学习不限时段 | 惊喜限定 16–23 点（白天到达不污染） |
| P4 | 21 天成长几乎冻结（敏感仅 +0.08） | 塑性曲线按 depth 档，4 天后就衰减到 0.15 | 塑性改按**周龄**分段（1.0→0.7→0.5→0.3） |
| P4 | reactivity 永远不涨 | 阈值要求刺激 ≥3，单日不可达 | 降到 ≥2 |
| P4 | 日记措辞雷同 | 变体"排序取 top"，总选权重最高句 | 改**加权随机**选变体 |

## 9. 整体结论

**设计目标全部达成**：

1. **8 项可观察生命瞬间**（DESIGN §5）在数值上出现并可复现：吓一跳、出门后蔫/回家精神一振、深夜呼吸变慢、睡眠叙事、巡逻改主意、困意、被打断后又凑过来、无用的事；
2. **旧 life 模块的 6 个"无法优化点"**（DESIGN §6）被机制性解决：异常事件门控→惊吓（非骰子）、驱力波竞争→挣扎、River+气质→成长生理化、LivingLoop→自持状态机、Will→改主意闭环、本地波形→断网不塌；
3. **成长性可分辨**：多刺激 vs 平静、亲密 vs 疏离，不同经历产出可统计区分的 trust 与个性；
4. **零 LLM 成立**：全部生命感来自本地确定性动力学，LLM 仅在生产环境"变成语言"时低频介入，断网生命感不塌。

## 10. 局限（诚实声明）

| 局限 | 说明 | 缓解方向 |
|---|---|---|
| 仿真非真实感知 | 事件为脚本/随机生成，真实视觉/语音的误检、漏检、时序抖动未覆盖 | 接入真实感知后做灰度回放验证 |
| 参数未经真人标定 | τ/阈值/漂移幅度为工程合理值，未经真实用户长期数据校准 | 上线后按日志回归调参 |
| 模板成文的丰富度上限 | 日记为模板×变体，长尾表达不如 LLM | 生产环境 LLM 压缩生命流成文（模板兜底，已留接口） |
| 未验证长周期（>月） | 最长 21 天，人格稳定后的"再成长"与创伤修复未覆盖 | 后续 90 天长周期仿真 |
| 运动/具身未接入 | PULSE 现验证"内心"，移动底盘/导航的生命感联动未验证 | 接入运动系统后验证"想去→真的走过去" |
