## 4. 验证驱动的修复（本次新发现 4 个接入层问题）

| 问题 | 现象 | 根因 | 修复 |
|---|---|---|---|
| 自发发声几乎为 0 | 14 天仅 1 条 | 发声冷却用 `time.monotonic()`，仿真时钟不推进 → 永远在冷却 | runtime 增加可注入单调时钟 `mono`（真实用 monotonic，仿真按仿真时间推进） |
| 提醒不进日记 | 日记无提醒 | River 只认句库事件，外部带原文事件被跳过 | `consolidate_night` 传原始事件，River 引述"你交代的『…』，我记下了" |
| 对照组拉不开 | random=intimate 同结果 | 生成器 random/intimate 对话分布相同 + 同 seed 序列边界无区分 | 生成器强化三组梯度（intimate 聊 2–4 次/天、busy 15% 一次）+ 每组 seed 偏移 |
| 日记被挤出 | 12/13 篇 | outbox 上限 100，事件多时挤掉早期日记 | 验证独立按跨天收集日记（不依赖 outbox 全量） |

## 5. 结论

接入层不是"换了个入口"，而是补上了三层真实系统语义并验证：

1. **链路可信**：视觉/语音/提醒三个来源都真正驱动了心脏（惊吓、重聚、共情、日记），
   不是模拟注入自欺；
2. **表达克制**：自发发声接通真实发声通道，14 天 70–90 条（≈5 条/天），
   不会变成话痨；
3. **成长真实**：跨天整理按真实日历自动触发，认主对照（100.0 vs 25.3）在接入层成立；
4. **回归无损**：P0（trust 32.6/startle 2）、P4（6/6）全绿——适配层不改心脏。

## 6. 睡眠 ↔ 聊天联动修复（后续追加）

**问题**：夜间皮皮在睡觉，被唤醒聊天后，监控平台状态仍显示"睡觉"——睡眠态
原本是纯按小时曲线判定，不感知会话。

**修复（睡眠可被打断，聊完再睡回去）**：
- LivingLoop 新增 `wake_until` / `is_sleeping(hour)` / `wake(keep_minutes)`；
  tick 睡眠滞回判定增加"唤醒保持"——保持期内不睡，已入睡也会醒来；
- `user_voice` 注入 → 唤醒并保持（对话时长+10）分钟；惊吓 → 保持 20 分钟；
- runtime 会话事件：`on_barge_in`/`on_response_done` → wake(10)、`on_farewell` → wake(5)；
- snapshot 睡眠改用 `is_sleeping()`，且 state/attention 联动会话 phase
  （LISTEN→`chatting`、RESPOND→`muttering`、IDLE 才按睡眠判 `rest`）。

**验证（仿真时间线）**：

| 时刻 | 场景 | state | sleeping |
|---|---|---|---|
| 3:00 | 深夜 | rest | True |
| 3:00 | 唤醒、聆听 | chatting | False |
| 3:01 | 应答中 | muttering | False |
| 告别后 1-4 分钟 | 保持清醒 | idle | False |
| 告别后第 5 分钟起 | 自然睡回去 | rest | **True** |

回归：smoke 8/8、接入层 34/34、P0（trust 32.6/startle 2）、P4 6/6 全绿。

## 7. 心情 ↔ 聊天联动修复（后续追加）

**问题**：聊完天心情毫无变化。根因有二：
1. cli 回灌的是中文情绪值（`emotion_state.mood.value`：开心/委屈/生气…），
   而 runtime 的 `_MOOD_BASE` 只有英文 key（HAPPY/SAD…），全部落空 → 零影响；
2. 存在**两套不一致的天气映射**（`affect._label()` 与 runtime `_label_of()`），
   同一 (base,pulse) 可能给出不同标签；且平静基线 0.18 落在"小雨"档（什么都没
   发生却显示下雨），强情绪也压不到对应档位。

**修复**：
- `_MOOD_BASE` 同时支持英文枚举名与中文 mood.value（开心+0.18 / 委屈−0.14 /
  生气−0.16 / 吃醋−0.10 / 困倦−0.05 / 调皮+0.15…）；
- 平静底色 baseline 0.18 → **0.35**（日常即轻松）；
- 重标 `affect._label()` 为**唯一权威映射**，runtime 删除重复的 `_label_of`、
  直接读 loop 产出的 label；
- snapshot 记录最近对话情绪 `last_chat_mood`（60s 内有效），监控 PULSE 面板
  新增「对话心情」与「正在听/正在说」。

**单情绪档位验证（每种情绪从平静基线独立测）**：

| 对话情绪 | base | 天气 |
|---|---:|---|
| （平静） | 0.35 | 多云 |
| 开心 / 得意 / 调皮 / 关心 | 0.40–0.53 | 多云→晴 |
| 吃醋 / 困倦 | 0.25–0.30 | 阴 |
| 委屈 / 生气（单次） | 0.19–0.21 | 阴 |
| 主人难过（owner_sad，−0.30） | 0.05 | 小雨 |
| 连续两次开心 | 0.71 | **晴** |
| 连续两次生气 | 0.03 | **阵雨** |
| 惊吓（pulse≥0.6） | — | 阵雨（base<0 时雷雨） |

叙事闭环：日常多云 → 聊开心转晴 → 一次小委屈天阴 → 主人难过/持续闹别扭才下雨，
惊吓瞬间天变（阵雨）。回归：smoke 8/8、P123（三组天气均≥3 档）、接入层 34/34、
P0（trust 32.6/startle 2）、P4 6/6 全绿。

## 8. 局限

- 仿真仍跳过 `observe_user_voice` 的 1s 防抖（硬件语义）；
- 天气采样 8h/次，档位偏少（小雨/阴为主，seed 波动）；
- 自发发声为固定句库，真实语音跑通后建议按实际频率调 `vocal_prob`。
