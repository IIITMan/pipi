## 1. 验证目标

P0 不验证"好不好看"，只验证一件事：**注入真实作息与事件后，生命模块的内部动力学是否呈现类似生命的形态**——
有潮汐、有突发、有平复、有昼夜节律，而不是随机噪声或死数值。

## 2. 方法

| 项 | 值 |
|---|---|
| 仿真时长 | 72h（3 个完整日），dt=1s |
| 快循环 | Rhythm 1Hz 波形 / Tension 秒级回归 |
| 行为尺度 | Will 5s 决策 |
| 生命尺度 | River 每日入睡整理（3 次） |
| 采样 | 每 10min 一行（432 行），另记录全事件 |
| 随机性 | 器官各自固定 seed（rhythm=7, will=11），结果可复现 |

**场景脚本（固定事件 + 模拟视觉/对话数据流）**：

| 时间 | 事件 | 模拟来源 |
|---|---|---|
| 每天 0:00–7:00 | 睡眠（入睡时整理做梦） | 昼夜 |
| 每天 7:30 | 主人出门（视觉：owner_gone） | 视觉 |
| 每天 19:00 | 主人回家（视觉：owner_arrive） | 视觉 |
| 每天 19:10 / 21:30 | 对话两轮各 10min（语音：user_voice） | 对话 |
| D2 14:00 | 陌生人出现 2min（视觉：stranger） | 视觉 |
| D2 20:45 | 主人表情低落（视觉：owner_expression） | 视觉 |
| D3 3:05 | 深夜噪声（音频：意外声响） | 音频 |
| D3 10:00–11:00 | 主人在家安静工作（陪伴低张力段） | 视觉 |

## 7. 结论与下一步

- **P0 通过**：8 项可观察生命瞬间中 7 项在数值上出现，且全部由**机制因果**驱动
  （异常事件→惊吓、驱力竞争→挣扎、思念曲线→蔫），无一项依赖随机骰子；
- **关键强度确认**：惊吓、重聚、挣扎、昼夜四类"生命瞬间"的曲线形态与幅度均合理；
- **可进入 P1**：P1 心搏（Rhythm+Tension+Will+body）即在本包数值核心上叠加
  LivingLoop 编排与呼吸灯/表情表达；调参起点见 §6。
