## P0 · Will 决策滞回（不改冷却，改滞回）

核心原则：**不把机器人锁死在某个意图里，而是避免很小的数值变化就引发行为切换。**

| # | 任务 | 验收标准 |
|---|---|---|
| 1 | `switch_margin`：新意图必须明显领先当前意图才允许切换 | 两波接近时（差值 <margin）不切换；数值合法 |
| 2 | `min_dwell_time`：普通意图至少持续一段时间 | 非紧急意图不会在 N 秒内反复横跳 |
| 3 | `urgent_override`：紧急事件可立即打断普通行为 | 惊吓/安全/用户指令可绕过 1、2 |
| 4 | 当前意图失效/任务失败/环境重大变化 → 允许提前重新决策 | 任务完成后不残留旧意图 |
| 5 | 记录**切换原因**：新驱力占优 / 原任务完成 / 环境变化 / 紧急打断 | 日志可按原因统计：区分"合理灵活"与"无意义横跳" |

**验收总标准**：用实际数据（切换原因统计）证明——无关微扰不再导致切换；紧急事件仍即时响应；任务不被随意打断。

## P0 · 器官故障三级隔离

不能只依赖"单次异常记日志、循环继续"——NaN 传播会毒化其他器官，涉及硬件动作时更危险。

| 级 | 机制 | 验收标准 |
|---|---|---|
| 1 | **单次异常恢复**：输入不合法/结果越界 → 记录错误、拒绝本次更新、沿用最后一个有效状态 | 注入 NaN/±inf/越界/异常 dt → 状态不污染、循环继续 |
| 2 | **器官隔离**：某器官持续异常 → 暂时隔离，阻止无效状态传播，满足恢复条件后重新启用 | 隔离后其他器官正常；隔离期间该器官不产生动作意图 |
| 3 | **关键控制安全态**：故障可能影响运动/发声等硬件 → 停止受影响动作，交独立安全逻辑 | 模拟器官损坏 → 不会下发危险动作 |

补充要求：
- 显式检查 **NaN、±inf、越界值、异常 dt**。
- **仅 clamp 不够**：被限制到边界的异常值仍可能产生逻辑错误。
- 检查**更新前后的状态合法性**，区分"可安全修复的异常"与"需隔离的异常"。

## P1 · 验证体系：两类测试 + 纳入总矩阵

两类测试不能互相替代：数值合法 ≠ 行为合理；行为偶尔合理 ≠ 长期稳定。

| 类 | 覆盖 | 验收标准 |
|---|---|---|
| 动力学正确性 | 状态边界、确定性、时间跳变、事件重复、器官异常恢复、存档恢复 | 相同输入+初始状态 → 可复现相同结果；边界不失控 |
| 行为质量 | 意图切换率、任务完成率、主动发声频率、异常刺激后恢复、长时间独处表现、不同性格的可辨认差异 | 行为有连续性、能完成任务、不无故打断用户；S1 与 S4 性格差异可观察 |

附加要求：
- **多随机种子 + 不同事件顺序**（不再共用单种子）。
- 传感器**误报、漏报**、长时间离线和**重启恢复**。
- **30–90 天**信任演化、重复事件、时间跳变、长期无互动。
- 新增证据（P4、接入层 34/34、天气同步、搜索预警 19/19、自发发声历史等）**纳入总测试矩阵**，作为完整验证证据归档。
