## 1. 验证方法

与 P0 的固定事件脚本不同，本次验证喂入的是**随机生成的事件流**（"生成日子"），对 P1/P2/P3 做整体压力验证：

- **时长**：14 个仿真日 × 1440 分钟/日（跨认主关键期 14 天窗口），每仿真分钟 tick 一次。
- **三组对照**：

| 模式 | 设计意图 | 互动密度 |
| --- | --- | --- |
| `random` | 混合日常（对话/陌生人/低落/冷淡混杂） | 中 |
| `intimate` | 高互动（几乎每天对话、低冷淡概率） | 高 |
| `busy` | 忙碌疏离（几乎不对话、高冷淡概率、更常隔日才回） | 低 |

- **事件分布**（每天随机注入）：

| 事件 | 分布 |
| --- | --- |
| 早晨出门 | 80~95%（intimate 85 / random 80 / busy 95） |
| 回家时刻 | 提前 15:30-16:30（10%）/ 准点 17:00-20:00（12%）/ 晚归 21:00+（12%）/ 隔日清晨 6:00-8:00（12%） |
| 对话 user_voice | intimate/random 0-3 次；busy 15% 概率 1 次 |
| 陌生人 stranger | 40%（busy 10%） |
| 主人低落 owner_sad | 30%（busy 10%） |
| 安静陪伴 quiet_home | 50%（busy 30%） |
| 冷淡重聚 owner_ignored | random 20% / busy 35% / intimate 10%（当天有回家时） |
| 夜间噪声 night_noise | 第一周每晚必注入（观测习惯化），第二周 60% |

- **采样**：每 120 仿真分钟采样一次（呼吸/灯/挣扎/天气/trust/分离/思念/五波）；受惊与重聚事件**即时直测**（不受采样粒度影响）。

机制验证：`random` 与 `intimate` 信任持续爬升（认主期 ×3），`busy` 因互动天数 4 < 5 在关键期结束时被判定认主错过，且长期疏离导致信任回落到 31.2。

## 4. 验证过程中发现并修正的问题

| # | 类型 | 问题 | 修正 |
| --- | --- | --- | --- |
| 1 | 验证方法 | 120min 采样抓不到惊吓瞬间的呼吸脉冲（burst τ=20s） | 受惊事件即时直测：注入 1s 后读 `rate_bpm`，对比注入前基线 |
| 2 | 验证方法 | 思念"单调性"断言跨分离段失败（每次出门 sep 归零） | 按分离段分组，段内断言单调不减 |
| 3 | 机制（已在 P3 修复） | 白天任意时段回家都会被学进"傍晚归"期望 → 误判惊喜 | 惊喜判定限定 16:00–23:00 时段（P3 已修，本次随机流下惊喜均为下午/傍晚真提前） |
| 4 | 验证设计 | busy 组疏离度不足（两组都认主成功） | 降低 busy 对话概率（0-1 次→15%）、低落 10%、冷淡 35%，疏离效果成立 |

## 5. 结论

- **P1 心搏稳定**：分钟级驱动下 14 天呼吸始终有界（13.0–16.4 bpm）、睡眠慢而深、惊吓脉冲（+6 bpm 级）与安睡挣扎抑制全部成立，无发散/NaN。
- **P2 预感闭环**：错过/提前/习惯化在随机事件流中自然涌现（习惯化：第一周每晚夜噪仅 2 次受惊、D8 后为 0），意图切换与无用的事高频出现，天气随事件波动。
- **P3 羁绊成型**：思念单调饱和、重聚分级文本齐全、冷淡造成信任损失、认主成败由"关键期内互动天数"决定——亲密与疏离两组信任差距 38.4，机制区分度明确。

## 6. 局限

- 三组共用同一 `seed`，事件流前部有部分相似（呼吸/天气分布几乎一致），模式差异主要体现在互动密度——若要更强差异化可换 seed 重跑。
- 模拟数据未含"视觉输入"（人脸/表情/物体识别结果）——视觉事件流可在感知接入后注入 `owner_expression` 等键扩展。
- 14 天窗口仅覆盖认主关键期；长期（>30 天）信任饱和/个体差异演化未验证，属 P4（种子漂移）范围。
